# 比例・反比例パーク

小学6年生の算数「比例と反比例」を、表・式・グラフで同じ関係を確かめながら練習する学習アプリです。

## 対象

- 小学6年生（算数「比例と反比例」）

## 内容（全72問）

| 種類 | 問数 | 内容 |
| --- | --- | --- |
| 見分け | 12 | 表や場面から、比例・反比例の関係を見分ける |
| 表 | 16 | 表の空らんをうめる、決まった数（y÷x / x×y）を求める |
| 式 | 12 | 表から式を選ぶ、式に値を入れて計算する（反比例は y＝決まった数÷x） |
| グラフ | 16 | グラフの読み取り（比例は原点を通る直線、反比例は曲線）、表に合うグラフを選ぶ |
| 文章題 | 16 | あめの代金、水の量、長方形の面積、速さと時間など |

## 使い方

- 「比例だけ」「反比例だけ」「まぜまぜ」は10問ずつ出題されます。
- 「種類別れんしゅう」では、見分け・表・式・グラフ・文章題を種類ごとに練習できます。
- 答えを選ぶと、その場で正誤と解説が出ます（正しい考え方と、選んだ答えとの違い）。
- まちがえた問題は自動で記録され、「まちがえた問題」から何度でも再挑戦できます。正解すると克服として記録から外れます。
- 「学習の記録」で、解いた数・正解数・正答率（全体／比例／反比例）が見られます。

## 記録について

- 学習の記録は、使っている端末のブラウザ（localStorage）にだけ保存されます。外部のサーバーへ送信されることはありません。

## 技術メモ

- 静的なHTML/CSS/JavaScriptのみで動作します（外部API・外部サービスは使いません）。
- 共通基盤として、TT-senseiの edu-effects（学習UIのCSS）、sounds-recipe-（効果音）、navi-character-（ナビキャラ画像）を読み込んでいます。
- 問題はパラメータ（比例定数・積）から生成しており、`verify/verify.mjs` で全問の答えを再計算して検算しています（`node verify/verify.mjs`）。
